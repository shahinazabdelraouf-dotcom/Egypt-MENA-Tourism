Global Tourism Data Analysis & Power BI Dashboard

Project Overview

This project analyzes global tourism data to explore international tourist trends, compare tourism performance across countries, and understand the impact of the COVID-19 pandemic on the tourism sector.

The project uses World Bank tourism data and Power BI to transform historical data into meaningful visual insights.

Data Source

World Bank Open Data – Tourism Indicators.

Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization

Dashboard Structure

1. Global Overview

- Global tourist arrivals by country.
- Key tourism performance indicators.
- Global tourism trends from 2015 to 2020.

2. Egypt & MENA Analysis

- Tourism trends in Egypt from 2015 to 2020.
- Comparison between Egypt and the MENA region.
- Year-based interactive filtering.

3. COVID-19 Impact

- Comparison of tourism indicators between 2019 and 2020.
- Analysis of percentage changes.
- Exploration of the pandemic's impact on international tourism.

Key Objectives

- Analyze global tourism trends.
- Compare Egypt's tourism performance with the MENA region.
- Identify changes in tourist arrivals.
- Evaluate the impact of COVID-19 on the tourism sector.

Project Outcome

An interactive Power BI dashboard providing insights into global tourism trends, Egypt's regional performance, and the impact of COVID-19 on international tourism.

Data Source

World Bank Open Data: https://data.worldbank.org/
